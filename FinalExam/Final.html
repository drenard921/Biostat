a <- tab[1,1]; b <- tab[1,2]
c <- tab[2,1]; d <- tab[2,2]

# Odds Ratio
OR <- (a*d)/(b*c)
logOR <- log(OR)
se_logOR <- sqrt(1/a + 1/b + 1/c + 1/d)
CI_OR <- exp(logOR + c(-1,1)*1.96*se_logOR)

# Risk Ratio
p1 <- a/(a+b)
p0 <- c/(c+d)
RR <- p1/p0
# Wald SE for log(RR)
se_logRR <- sqrt( (1/a) - (1/(a+b)) + (1/c) - (1/(c+d)) )
CI_RR <- exp(log(RR) + c(-1,1)*1.96*se_logRR)

# Pretty output
out <- data.frame(
  Measure = c("Odds Ratio (drug1/drug2)", "Risk Ratio (drug1/drug2)"),
  Estimate = c(OR, RR),
  Lower95CI = c(CI_OR[1], CI_RR[1]),
  Upper95CI = c(CI_OR[2], CI_RR[2])
)

Q2 (d)

Under the null hypothesis of no association between drug regimen and achieving A1c < 7,
we assume the row and column variables are independent.
In that case, the probability of being in a given cell is the product of its row probability and column probability.
Multiplying these probabilities by the total sample size \(N\) gives the expected count formula:

\[ E_{ij} = \frac{(\text{row total}_i) \times (\text{column total}_j)}{N} \]

For example:
- \[E_{\text{drug1},<7} = \frac{156 \times 184}{344} = 83.48\]
- \[E_{\text{drug1},\ge 7} = \frac{156 \times 160}{344} = 72.52\]
- \[E_{\text{drug2},<7} = \frac{188 \times 184}{344} = 100.52\]
- \[E_{\text{drug2},\ge 7} = \frac{188 \times 160}{344} = 87.48\]

Q2(e): Chi-square statistic

We test independence using the Pearson chi-square:

\[ \chi^2 \;=\; \sum_{i,j} \frac{(O_{ij}-E_{ij})^2}{E_{ij}}, \quad \text{df} = (r-1)(c-1) = 1. \]

# Recreate observed counts (rows: drug1, drug2; cols: <7, >=7)
O <- matrix(c(110, 46,
              74, 114),
            nrow = 2, byrow = TRUE,
            dimnames = list(Drug = c("drug1","drug2"),
                            A1c  = c("<7", ">=7")))

# Expected counts from part (d)
row_tot <- rowSums(O); col_tot <- colSums(O); N <- sum(O)
E <- outer(row_tot, col_tot) / N

# Chi-square components and statistic
contrib <- (O - E)^2 / E
chisq_stat <- sum(contrib)
df <- (nrow(O)-1)*(ncol(O)-1)
pval <- 1 - pchisq(chisq_stat, df = df)

# Nicely show contributions (optional)

Methodology:
The Welch’s t-test was used for the unadjusted comparison because it compares the means of two independent groups without assuming equal variances — a safer choice given our small and unequal group sizes. Linear regression was then used for the adjusted analysis to estimate the mean CT difference while controlling for age and sex, reducing confounding and isolating the association with survival.

Interpretation: The unadjusted result is borderline significant at α = 0.05. After adjustment, the mean CT difference is statistically significant, supporting the hypothesized relationship.

3) Required Sample Size for 90% Power

Formula:
\[ n_{\text{per group}} = 2 \left( \frac{z_{1-\alpha/2} + z_{1-\beta}}{\Delta / s} \right)^2 \]

  • \[z_{1-\alpha/2} = 1.96\] for α = 0.05 (two-sided)
  • \[z_{1-\beta} = 1.2816\] for 90% power
  • \[s = 4.655\] (larger pilot SD for conservatism)
  • \[\Delta = 4\] (clinically meaningful mean difference)

Conclusion

Pilot data suggest survivors present with higher CT values, indicating lower viral load at admission. Adjustment for age and sex strengthens the statistical evidence. The sample size estimate of 29 per group offers a practical target for designing the larger study, though results should be interpreted cautiously due to the small pilot sample.
