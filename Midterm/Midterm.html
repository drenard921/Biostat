Question 3(b)

Sample size calculation for a follow-up trial:
You want to detect a 0.5-unit difference in mean antibody response with a standard deviation of 1.5, 90% power, and a two-sided test.

We use the sample size formula for comparing two independent means:

\[ n = \left( \frac{Z_{1 - \alpha/2} + Z_{1 - \beta}}{\Delta / \sigma} \right)^2 \]

Where:

  • \[\Delta = 0.5\] (effect size to detect)
  • \[\sigma = 1.5\] (standard deviation)
  • \[\alpha = 0.05\] (significance level for a two-sided test ⇒ 95% confidence)
  • \[\text{Power} = 90\% \Rightarrow \beta = 0.10\]

Although the study is powered at 90%, we still use a 95% confidence level for hypothesis testing (i.e., \[\alpha = 0.05\]), which is standard practice in clinical trials and reflected in the formula above.

From the standard normal table (using R):

# Z-score for 95% confidence level (two-sided test)
qnorm(1 - 0.05 / 2)  # 1.959964
[1] 1.959964
# Z-score for 90% power
qnorm(0.90)  # 1.281552
[1] 1.281552

Plugging into the formula:

We substitute the values into the formula for sample size:

\[ n = \left( \frac{1.96 + 1.28}{0.5 / 1.5} \right)^2 = \left( \frac{3.24}{0.333} \right)^2 = (9.72)^2 \approx 94.5 \]

Checking work with R

# Z-scores
Z_alpha_2 <- qnorm(1 - 0.05 / 2)  # ≈ 1.96
Z_beta <- qnorm(0.90)            # ≈ 1.28

# Inputs
delta <- 0.5
sigma <- 1.5
Z_total <- Z_alpha_2 + Z_beta

# Sample size calculation
n <- (Z_total / (delta / sigma))^2
n  # ≈ 94.5
[1] 94.56681

Answer:
You would need approximately 95 participants per group to detect a 0.5-unit difference in mean antibody response with 90% power, using a two-sided test at the 0.05 significance level.

We are looking for the probability that 2 or more false positives occur out of 5 people who do not have malaria.

This is a binomial probability problem with:

  • \[n = 5\] (number of individuals tested)
  • “Success” = a false positive test result

From Part B, we calculated the test specificity as:

\[ \text{Specificity} = 0.859 \]

So the probability of a false positive is:

\[ P(\text{false positive}) = 1 - \text{Specificity} = 1 - 0.859 = 0.141 \]

Computation

We want the probability of at least 2 false positives:

\[ P(X \geq 2) = 1 - P(X < 2) = 1 - P(X = 0) - P(X = 1) \]

# Define probability of false positive
p_fp <- 1 - 0.859  # = 0.141

# Compute probability of at least 2 false positives in 5 tests
p_at_least_2 <- 1 - pbinom(1, size = 5, prob = p_fp)
p_at_least_2
[1] 0.1484515

The result is approximately 0.148, meaning there is a 14.8% chance that at least 2 out of 5 people without malaria would receive a false positive result.
